# BRIEF — FitCast Photo Garments

**Что строим.** Модуль, который по фото вещи (сначала — только футболка, снятая ровно спереди на плоскости) строит пиксельную low-poly одежду на изменяемом манекене и сохраняет её в гардероб по ID.

**Два независимых упрощения.** Low-poly — про геометрию (фиксированная топология шаблона). Пикселизация — про текстуру, и она выполняется ПОСЛЕ распознавания, сегментации и UV-переноса.

**Два режима масштаба.** Без мерок — нормализованная визуализация без сантиметров. С мерками — введённые размеры сохраняются, несовместимость сообщается. Фото не даёт сантиметры автоматически.

**Что не входит.** Фото одежды на человеке, точная реконструкция скрытых поверхностей (спинка условна), тканевая симуляция, гарантии посадки, рекомендатель образов, большой каталог.

**Стек.** Three.js 0.185.1 + TypeScript 5.9 + Vite 7 (standalone dev-страница внутри репозитория FitCast). Без Blender, без CUDA. ML-провайдеры выбираются на этапах 06–07 и должны быть заменяемыми.

**Контрольные точки.** A — силуэт и UV футболки (этап 03). B — фото → категория → маска (07). C — сквозная футболка (12). D — брюки и юбка (17).
