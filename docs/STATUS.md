## Реализовано (код написан)
- 01 Окружение: Vite 7 + TS 5.9 + three 0.185.1; `index.html` (шаблон, виды, checker, проверки) и `garment.html` (цепочка, 8 шагов).
- 02 Контракты: `AvatarAdapter` + тестовый/Object3D адаптеры (заморожены), `GarmentRecord` с provenance, `PipelineStore` (отмена/инвалидация вниз по цепочке), стороны носителя + мост к сторонам снимка.
- 03 Шаблон `tshirt-basic 1.2.0` (`tshirt-basic-topo-1`): 14 ограниченных параметров + правила, 5 UV-островов, 21 проверка + блокирующий скрипт; горловина исправлена (D-10); лимиты расширены до реальных пропорций (D-15).
- 05 Фото: JPEG/PNG/WebP, EXIF-ориентация, рабочая копия ≤1024, HEIC — сообщение, сброс, освобождение URL.
- 06 Категория: локальный MobileNetV2-12 (ImageNet → tshirt/pants/skirt/other), некалиброванные scores подписаны, подтверждение/ручной выбор кнопками, неподдерживаемое отклоняется.
- 07 Маска: U²-Netp в Web Worker; слои model/post/user; ползунок порога без повторного инференса; возврат фрагментов; заливка дыр только по явной команде (вырез сохраняется); предупреждение о внутренних разрывах; эвристический статус отдельно от подтверждения пользователя; кисть, undo, зум.
- 08 Ориентиры: 13 точек по силуэту (контур/оболочка/дефекты), 7 проверок, горловина по умолчанию с пометкой, редактор перетаскиванием (`user_adjusted`).
- 09 Параметры вещи: относительные (без см), слои estimated / applied+clamped / user / resolved с provenance; выбор шаблона через реестр.
- 10 UV: кусочно-аффинный перенос переда и видимой половины рукавов внутри подтверждённой маски; bleed + заливка основным цветом; спинка/воротник/задние половины помечены «не восстановлено по снимку».
- 11 Цвет: медианный основной цвет (ручной выбор), низкочастотная коррекция освещения (по умолчанию 0), raw и corrected отдельно.
- 12 Пикселизация 64/128/256 + палитра + сила (дизеринг выкл.), просмотр футболки без тела (вращение, зум, спереди/сзади/3-4, исходная/пиксельная), экспорт JSON + PNG, возврат к любому шагу.

## Ограничения
- Классификатор ImageNet — не одежный (~3/14 футболок требуют исправления); scores некалиброваны; сегментация теряет части при низком контрасте (синяя 91ebc326 — сложный пример, маска НЕ считается готовой).
- Статусы ok/suspicious — эвристики; точность маски и ориентиров без ручной разметки не заявляется.
- Горловина по силуэту обычно не видна → по умолчанию (жёлтые точки), требует проверки; подвёрнутые рукава ломают оценку рукавов.
- Одно фронтальное фото: спинка, воротник, задние половины рукавов — основной цвет, явно «не восстановлено». Второе фото не поддерживается.
- Сантиметры не вычисляются; ввод мерок не сделан.
- Перенос и пикселизация на главном потоке (~1 с на 1024²); атлас использует ~45 % высоты под перёд (256 px ≈ 120 текселей на перёд).
- Растяжение UV на кокетке ×2.48 (предупреждение).
- Локальный гардероб (этап 14, IndexedDB) не сделан — только экспорт файлов. Лишний `ort-wasm-*.jsep.wasm` (29 МБ) в сборке.
