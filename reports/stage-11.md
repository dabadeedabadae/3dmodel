# Этап 11 — Цвет и осторожная коррекция освещения
Статус: выполнено

## Изменения
- `src/image/color.ts`: основной цвет — медиана RGB внутри эродированной маски без 5 % самых тёмных и светлых пикселей; ручной выбор цвета (`input type=color`) с provenance `user_adjusted`. Коррекция освещения — деление яркости на её низкочастотное поле (маскированный box-blur, радиус ≈ 1/6 кадра), сила 0…1, **по умолчанию 0 (выключена)**; усиление ограничено 0.4…2.5. Мелкие детали (буквы) меньше радиуса и не сглаживаются. В UI подписано, что это не восстановление albedo.
- Исходная и скорректированная UV хранятся отдельно (`uv_raw`, `uv_color_corrected`); пикселизация берёт скорректированную, если она включена.
- Цветовое пространство: canvas sRGB → `DataTexture.colorSpace = SRGBColorSpace`, `renderer.outputColorSpace = SRGBColorSpace` (three 0.185).

## Реально запущенные проверки
- Puma: авто-цвет `#cc2840`; поле освещения 0.95…1.06 (почти ровный свет); UV до/после коррекции 0.5 сохранены (`*-4-uv-raw.png`, `*-4-uv-lit.png`). Серая: `#948278`, полосатая: `#697080` (медиана полос — ожидаемо), синяя: `#213055`.
- vitest: медиана по синтетическому снимку точна.

## Ограничения
- Сравнение до/после на нескольких однотонных и принтованных — только визуальное, числовой метрики нет.
- Тень и тёмный принт одного масштаба неразличимы (по определению метода).
