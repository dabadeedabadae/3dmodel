# Этапы M01–M04 — процедурный манекен (контрольная точка E)
Статус: код написан, проверки запущены в контейнере; ожидает утверждения E. Нативный macOS/Safari — не проверено.

## Что сделано
- **M01 Параметры** (`src/body/params.ts`): 22 параметра фигуры в метрах/радианах/отношениях с явными лимитами; два базовых набора пропорций (`sex` 0/1 = муж/жен) и 6 пресетов пропорций (не размеров). Анатомические правила `clampBodyParams`: сегменты не длиннее роста; талия ≤ груди и бёдер; плечи не уже грудной клетки; акромион не ниже подмышки; свисающая рука не входит в торс ни на одном уровне (грудь/под грудью/талия/бёдра) — разрешено до 1 см «утопления» плеча в эллипс грудной клетки (реальный бок грудной клетки площе эллипса); конечности сужаются; два бедра помещаются под тазом; голени не соприкасаются; выступ груди ограничен. Каждая правка отдаётся с причиной (видно в UI как «было → стало — причина»). Запрошенные значения (`requested`) хранятся отдельно от применённых (`params`) — ограничения не накапливаются (тест A→B→A).
- **Каркас** (`src/body/anatomy.ts`): высоты (пах, бёдра, талия, под грудью, грудь, подмышка, дельта, плечо, основание шеи, подбородок, макушка) из канона (рост = headRatio голов, ноги = legRatio·H, торс = torsoRatio·H, доли торса для колец), эллипсы сечений торса из обхватов (периметр Рамануджана), оси рук/ног с радиусами, голова/кисти/стопы; `torsoCrossSection(y)`, капсулы и знаковое расстояние для будущих проверок посадки.
- **M02 Сетка** (`src/body/buildBody.ts`): 7 замкнутых частей (торс+шея+голова одной трубкой, 2 руки с кистями, 2 ноги, 2 стопы), 380 вершин / 732 треугольника (10 сегментов на торс и голову, 6 на конечности — low-poly по референсу пользователя), топология `body-basic-topo-1` фиксирована (ориентация граней «запечена» один раз по знаку объёма). `updateBody` всегда пересчитывает от параметров.
- **Проверки** (`src/body/checks.ts`, `npm run check:body`, exit 1 при провале): конечность, нет вырожденных, каждая часть — замкнутое многообразие, согласованная ориентация, положительный объём (нормали наружу), зеркальная симметрия, стопы на полу, макушка = рост, конечности вне торса и не пересекают друг друга, рука не глубже 1 см в торсе, фиксированная топология.
- **M03 Скелет** (`src/body/skeleton.ts`): 19 костей (hips…head, по стороне: shoulder/upper_arm/forearm/hand, thigh/shin/foot), веса по кольцам (≤2 кости, смешивание на суставах; боковая часть дельты частично следует за рукой), `SkinnedMesh`. Поза покоя = сгенерированная сетка (тест: скиннинг с единичными трансформами совпадает с вершинами).
- **M04 Страница** `body.html` (`src/ui/bodyApp.ts`): ползунки с подписями в см/градусах, переключение базовых пропорций, пресеты, виды, wireframe/flat, ориентиры и капсулы, части цветом, отчёт проверок на странице, блок применённых ограничений, экспорт JSON. Рост вводится в см (параметр `height`), подписи высот в см — пропорции канона, не мерки человека.
- **Адаптер** `ProceduralBodyAdapter` реализует `AvatarAdapter` (+ `getFrame/getCrossSection/getCapsules`). Это свой манекен проекта (`kind: production`), но по-прежнему не `Body.tsx` FitCast.

## Реально запущенные проверки
- `npm run check:body` (300 случайных наборов) — PASS, 300/300; из них 295 потребовали анатомических ограничений (случайные комбинации намеренно экстремальные). Отдельный прогон на 1000 — 1000/1000. `reports/stage-M02-checks.json`.
- `npm run verify` — typecheck, vitest **59/59** (13 новых тестов тела: лимиты, правила, монотонность, сечения, геометрия, A→B→A, капсулы, веса, поза покоя, контракт адаптера), check:tshirt PASS, check:body PASS, build 3 страниц. `reports/stage-M04-verify-log.txt`.
- `npm run render:body` — 21 рендер без ошибок (`renders/stage-M/`), лист `renders/stage-M-e-sheet.png`: муж/жен M спереди/сбоку/сзади/3-4/wire, пресеты S/L, ориентиры, экстремальные ползунки (широкая грудь + узкие плечи → ограничения; высокий худой), вид сверху.
- Высоты ориентиров для пресетов (см): male-m пах 82, талия 109, грудь 124, плечо 136, основание шеи 142, подбородок 152 при росте 175; female-m пах 76, талия 100, грудь 114, плечо 125 при 163 — в пределах типичной антропометрии (не измерения).

## Ограничения и что видно на рендерах
- Low-poly: плечи и бёдра угловатые (10 вершин на кольцо торса, 6 на конечностях — намеренно, стиль low-poly); стык ног с тазом виден как грань; кисти — бруски, стопы — клинья, лица нет (по решению «чуть детальнее капсул»).
- Руки в A-позе отведены на 21–28°: это требование правила «рука не входит в торс» для эллиптической грудной клетки; для посадки рукавов это удобно, для «реалистичной стойки» (10–15°) понадобится уплощение бока торса (отдельная правка каркаса).
- Пресеты S/M/L отличаются обхватами, на маленьких рендерах разница малозаметна — смотреть на странице.
- Поз нет (P-этапы); скелет только в позе покоя.
- Проверено только в headless Chromium контейнера; Mac — не проверено.
