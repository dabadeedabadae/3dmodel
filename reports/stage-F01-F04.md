# Этапы F01, F02, F04 — посадка футболки на манекен (F03 брюки/юбка — ещё не начато)
Статус: код написан, проверки запущены в контейнере; F03 (шаблоны брюк и юбки) не начат — контрольная точка F пока **частичная** (футболки на манекене есть, низа нет).

## Что сделано
- **F01 Выравнивание** (`src/fitting/fitTShirt.ts`): один масштаб «метры на единицу шаблона» из одного якоря — по груди (эллипс груди тела + свобода) или по плечам; по вертикали горловина вещи (спинка ряда 6) ставится на основание шеи тела, плечевые точки вещи висят над акромионами по собственному наклону плеча вещи. Пропорции с фото (`params.resolved`) не меняются и не перезаписываются.
- **F02 Свобода и проверка колец**: таблица ease (грудь 3 см, талия 3.5, подол 3.5, плечо 0.8, рукав 1.5; множитель в UI ×0.5…×2). Каждое кольцо вещи (подол, талия, грудь, подмышка, плечо, манжеты) сравнивается с сечением тела на своей высоте (эллипс с выступом груди; рукава — с капсулами руки): статусы `tight / ok / loose / free` (free — тела на этой высоте нет, вещь свисает). Режим «подогнать по телу»: нужные параметры шаблона расширяются через его же clamp и записываются как `fitAdjust` (имя, было → стало, причина); затем рукава перецентрируются на ось руки с радиусом ≥ рука + ease, и оставшиеся вершины выталкиваются радиально из эллипса/капсулы. Режим «как на фото»: ничего не меняется, пересечения и натяг показываются честно (на всех пресетах футболка «как на фото» пересекает руки — рукава с фото направлены горизонтально, а рука висит).
- Всё пересчитывается от шаблона каждый раз (тест детерминизма), слой посадки хранится отдельно: `GarmentRecord.fit` (тело, пресет, якорь, масштаб, смещение, fitAdjust, статусы колец, статус, число вытолкнутых вершин, прошли ли проверки) и `record.avatar.fit` (`ok / out_of_range / incompatible`). Снятие с манекена очищает `fit` и возвращает вещь к её форме.
- **F04 Просмотр на манекене** (`garment.html`, шаг 8): чекбокс «На манекене», пресет пропорций, якорь масштаба, «подогнать по телу», множитель свободы, таблица колец, список изменённых параметров, результаты проверок. Виды спереди/сзади/3-4/сбоку, исходная/пиксельная текстура, манекен с flat shading.
- **Проверки**: `npm run check:fit` (блокирующий, в `verify`): 5 футболок (каноническая + 4 из точки C) × 6 пресетов в режиме подгонки — ни одной вершины внутри тела (допуск 2 мм), ось руки внутри обоих рукавов; дополнительно «как на фото» — информационно. `reports/stage-F02-checks.json`.

## Реально запущенные проверки
- `npm run check:fit` — 30/30 PASS; подгонка меняла: `sleeveAngle` (почти всегда: рукава с фото 0…0.69 рад → 0.8, максимум шаблона), `cuffRadius` (рука толще манжеты), `depthRatio` (женские пресеты — грудь), `chestHalfWidth`/`hemHalfWidth` на крупных пресетах; выталкивание до 3–11 см (рукава на ось руки).
- `npm run e2e:fit` — Chromium: Puma и полосатая через всю цепочку → на манекен male-m / female-m / male-l (подгонка и «как на фото»), снимки спереди/сзади/3-4/сбоку, панель посадки, UI-чекбокс включает/выключает, снятие очищает запись. PASS, `reports/stage-F04-e2e.json`, `renders/stage-F/`, лист `renders/stage-F-sheet.png`. Принт PUMA на груди, не зеркален, рукава вдоль рук.
- vitest 64/64 (+5 тестов посадки: нет пересечений на всех пресетах, масштаб только от якоря, «как на фото» ничего не трогает, детерминизм, fitAdjust только расширяет и объясняет). `npm run verify` PASS (`reports/stage-F04-verify-log.txt`).

## Ограничения
- Ограничение шаблона `sleeveAngle ≤ 0.8 рад` (46°) меньше наклона висящей руки (≈68°): рукава доводятся до оси руки выталкиванием/перецентрированием колец, а не параметром — это видно как лёгкий излом у проймы. Расширение лимита требует переработки правил рукава шаблона (не делалось).
- Подол ниже паха «свисает» (статус free): ноги не учитываются при подгонке торса — для футболки это правильно, для длинных вещей понадобится проверка с бёдрами.
- Статусы колец — по минимальному зазору вдоль кольца; это не «размер подходит/не подходит», а геометрический зазор на упрощённом теле.
- Горловина не вытягивается под шею — только проверка (WARN) и выталкивание радиально.
- F03 (брюки, юбка) не начат; проверено только в headless Chromium; Mac — не проверено.
