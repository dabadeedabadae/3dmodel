# Этап 09 — Выбор шаблона и параметров вещи
Статус: выполнено

## Изменения
- `src/shape/params.ts`: `selectTemplate(category)` через реестр (`tshirt → tshirt-basic 1.2.0`, остальное → null, брюки на футболку не направляются). `estimateParams` — отношения фото → относительные параметры шаблона: якорь — каноническая ширина груди (0.88 = 2·0.44); длина, подол, плечи, глубина проймы, длина рукава, радиус манжеты, наклон рукава, ширина и спуск горловины. Не видны на фото и берутся из шаблона: `depthRatio, neckBackDrop, collarWidth, shoulderSlope` (подписано в UI и в `note`).
- Три слоя хранятся раздельно: `estimated` (сырое по фото, может выходить за лимиты) → `applied` + список `clamped` (что и почему ограничил шаблон) → `user` (ползунки) → `resolved`. `toGarmentParams` даёт `GarmentRecord.params` с provenance `estimated | user_adjusted | default` и заметкой об ограничении.
- `scale: { kind: 'none' }` — сантиметры не вычисляются; поля для см нет.
- Лимиты шаблона расширены до реальных пропорций вещи (D-15), канон и UV не изменились; версия 1.2.0.
- UI: таблица «оценка по фото / принято шаблоном / ваше значение / итог», ползунки, сброс своего значения, «Подтвердить форму».

## Реально запущенные проверки
- e2e: Puma — ни одного ограничения (длина 1.28 отн. ед. принята после расширения лимитов; до D-15 была бы обрезана до 0.95); полосатая — `neckFrontDrop 0.18→0.15`, `shoulderHalfWidth 0.43→0.44` (правило «рукава не выше горизонтали»); серая — `cuffRadius 0.46→0.30`, `sleeveAngle 1.55→0.80` (подвёрнутые рукава — ожидаемо). Все ограничения видны в таблице и в записи.
- vitest: user > applied(estimated), provenance по каждому параметру, сырое значение 9 сохраняется при ограничении.
- Изменение ползунка сбрасывает `shape_confirmed` и всё ниже; e2e `reentry` подтверждает.

- Нет ввода мерок пользователем (длина/ширина в см) — поле `scale` подготовлено, UI не сделан.
