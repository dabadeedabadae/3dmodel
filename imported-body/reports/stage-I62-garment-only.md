# I-62 — одежда без тела на эталоне

**Результат:** фигура `outfit04` «Классическая рубашка и брюки». Рубашка — отдельная сетка вещи, голова, руки
и брюки — эталона.

## Код
- `scripts/garment-source.ts` (новый). Сетка одной вещи → `out/outfit-<id>.json` на эталоне. Шаги:
  - срез концов рукавов;
  - дробление треугольников;
  - равномерный масштаб;
  - высота подмышки;
  - ось рукава;
  - ограничение радиуса.
- `scripts/layer-outfit.ts`:
  - `prealigned` без пересчёта высот;
  - `floorSleeves` по отрезкам среза;
  - `smoothSleeves` со сглаживанием кромки манжеты;
  - лимит сдвига от пересечений;
  - отладка `IB_DEBUG` (места пересечений по этапам);
  - переключатели `IB_NO_CUFF`, `IB_NO_FLOOR`, `IB_CUFF_GAP`, `IB_SLEEVE_SMOOTH`.
- `scripts/prepare-outfits.mjs`: записи с `topMesh` в `assets/outfits.json`.
- `viewer/main.ts`: `?cam=x,y,z&look=x,y,z` для крупных планов.

## Запущено и проверено
- Ход по пересечениям рубашки с видимыми частями:
  - 11 — первый вариант;
  - 22 — без пересчёта высот;
  - 19 — новый «пол»;
  - 0 — срез крышки рукава.
- `npm run ib:outfits`: PASS по всем 4 фигурам; outfit01–03 — те же PASS, что и до I-62.
- Крупные планы (ворот, плечо, подол, предплечье спереди, снизу и сзади, манжета с 4 сторон):
  - после сглаживания предплечье гладкое, кромка манжеты — ровное кольцо;
  - ворот прижат к шее.
- Рендеры на пяти телосложениях: `renders/ofit04-{base,tq,slim,round,athletic,tall}.png`.
- Сайт FitCast: `npm run figure:sync` → `figure-04` (4758 вершин). Рубашка открыта на `/fitting` и выбирается
  кнопкой комплекта, ошибок в консоли нет.
