# Фото футболки на одетой фигуре (I-51) — 2026-11-18

## Написано
- `imported-body/src/photoMap.ts` — опорные точки снимка, валидатор правдоподобия рукавов, перенос на верх фигуры.
- `imported-body/scripts/photo-garment.ts`, `npm run ib:photo` — пакет вещи из фото (маска U²-Netp, ориентиры, основной цвет, текстура без фона) и блокирующая проверка переноса.
- FitCast: `frontend/lib/figure/photoMap.ts` (копия), просмотрщик рисует лицевые грани верха с фото; `npm run garments:sync`; блок «Фото на футболке» в `/fitting`.

## Запущено и проверено (macOS, Node 26.9)
- `npm run ib:photo` — PASS: 14 фото × 3 фигуры; блокирующих 5 фото с «ok» и без пометок валидатора (0–1 перевёрнутая грань на фигуру, corr торса 0.96–1.00, рукава 0.87–0.99), остальные — WARN «нужна проверка точек» (6 с «uncertain» от оценщика, 3 помечены валидатором).
- Негативный контроль: зеркальный перенос → FAIL, код 1.
- Глазами в `/fitting`: надпись на груди читается и не зеркальна, полосы горизонтальны, спинка и рукава — основным цветом.
