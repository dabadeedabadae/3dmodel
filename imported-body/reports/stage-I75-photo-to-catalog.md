# I-75 (2026-11-24): фото → тип вещи → готовая 3D-модель → принт с фото

Схема, которую сдаём: человек фотографирует вещь, сайт сам предлагает её тип, берёт подходящую готовую 3D-фигуру
и кладёт на неё принт с фото. Всё считается на устройстве, фото для этого никуда не отправляется.

## 1. Тип вещи по фото (новое)

- Модель: MobileNetV2-12 из ONNX model zoo (ImageNet-1k, Apache-2.0, 14 МБ) — та же, что уже была в модуле
  (`public/models`), теперь и на сайте (`frontend/public/ml`, `npm run ml:sync`).
- ~35 классов ImageNet про одежду и обувь сопоставлены типам сайта: `fitcast/frontend/lib/garment/garmentType.ts`
  (одна карта для сайта и для оценки). Сайт: `lib/garment/category.ts`.
- В форме гардероба тип выставляется сам и подписан «Recognized from the photo, please check» (или «Best guess…,
  not sure»), рядом 2–3 запасных типа кнопками. Выбранный вручную тип помечается «Chosen by you». Ручной выбор не
  выдаётся за распознавание.
- Оценка `node --import tsx scripts/eval-garment-type.ts` (отчёт `reports/stage-I75-garment-type.json`):

| Набор | Верно сразу | Есть среди предложенных |
|---|---|---|
| 26 фото проекта (CC0, плоская раскладка) | 21 (81 %) | 22 |
| 12 фото каталога | 8 | 10 |

  Ошибки: платье из трикотажа → футболка, джинсовая юбка → джинсы, футболка на сложном фоне → брюки/платье,
  худи на молнии и куртка. Это подсказка, а не точность: человек подтверждает тип.

## 2. Фото → 3D для всех вещей каталога

Принт с фото теперь ложится не только на футболку, рубашку, худи, свитер, кардиган и брюки, но и на **пиджак,
куртку и пальто** (форма гардероба и проверка пакета на сервере `wardrobe.controller.ts`, e2e-тест дополнен).
Поло (фигура 17) использует тип «футболка».

## 3. Выбор фигуры по фото

Под одним типом бывает несколько фигур: «футболка» — футболка (01), лонгслив (15), поло (17). Длина рукава с фото
(по найденным точкам, относительно ширины плеч: футболки 0.16–0.36, длинный рукав 0.53–0.64, порог 0.45) теперь
выбирает фигуру с таким же рукавом (`look.sleeve` в `outfits.json` → `figures.json`, `lib/garment/look.ts`).
Вырез (V / круглый) по точкам не различается (глубина 0.21 почти на всех фото) — между свитерами 05 и 14 человек
переключает фигуру сам.

## 4. Женские фигуры

- Ширина корпуса под проймой на крупной женской сетке получалась заниженной (0.14 м при ~0.2): часть плеча
  считалась рукавом. Теперь она меряется и по сечению треугольников — одной функцией `torsoHalfWidth` для раскладки
  и для проверки (`photoMap.ts`, обе копии). Мужские фигуры не изменились.
- На глаз футболка на женской базе правильная (принт по центру, рукава с фото).
- `ib:photo` всё равно даёт 5 провалов «рукав развёрнут не от плеча к манжете» на женской базе 11 и пуловере 16:
  у базы рукав-«крылышко» ~8 см, и проверка «вдоль рукава» на нём почти не измеряет. Проверка не ослаблялась.
  На пуловере 16 у плеча видна полоса фона снимка — не исправлено.
