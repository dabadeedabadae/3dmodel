# Demo photos

Seven photos for `npm run seed:demo`. Source: **Clothing dataset** by Alexey Grigorev
(https://github.com/alexeygrigorev/clothing-dataset), licence **CC0 1.0** (`LICENSE-CC0.txt`). Same files as
`3dmodel/fixtures/photos`, copied so the seed works from a plain clone and in Docker.

`catalog/` — the project's own catalogue pictures of the outer layers (blazer, cardigan, jacket, coat, zip hoodie),
the same files as `frontend/public/catalog`; not part of the CC0 dataset.
